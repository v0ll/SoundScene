# SoundScene 0.2.2

A lightweight tray companion for **Dolby Access** on ASUS ROG Zephyrus laptops: instant profile
switching, per-profile hotkeys, scenes, and a graphic EQ without opening the Dolby app.

This release makes the controller model-agnostic. Nothing changes on the tested G14, but the app no
longer assumes its driver: the profile list, EQ width, range, and band frequencies are read from the
installed DAX build.

## Highlights

- **Driver-aware EQ** - the band count and `±dB` range come from the DAX session, and band
  frequencies from the installed `dax3_*` tuning XML. When the tuning file is missing, bands are
  labelled `B1`, `B2`, ... instead of pretending to know their Hz.
- **Driver-aware profile grid** - tiles are built from the names the driver reports, including
  modes SoundScene does not know. If a build reports no modes to an unpackaged caller, the six
  known profiles are used in Dolby's historical order, as before.
- **Package discovery by identity** - Dolby Access is located by publisher and the presence of
  `DAXRPCClient.dll` rather than one hardcoded package family, so OEM repackages and newer Store
  versions are found.
- **Scenes store the driver index** - recalling a scene survives a driver that reorders profiles.
  Older scene files without an index still load and use the stored profile name.
- **Diagnostics** now lists the discovered package paths, service version, profile catalog, band
  count/range, and tuning XML source, so a report from another model is actionable.

## Compatibility

- Tested on the ROG Zephyrus G14 GA403UV with Windows 11 and Dolby Access 3.27.
- DAX3-based models such as the Zephyrus G16 should work, but have not been verified on hardware.
- Requires Windows 10 2004 (build 19041) or newer, x64, **Dolby Access**, and the ASUS/Realtek
  Dolby Atmos driver. The driver alone is not enough; no Dolby binary is bundled or redistributed.

## Install

1. Download `SoundScene-Setup-0.2.2.exe` below.
2. The installer is not code-signed yet, so SmartScreen may say "Windows protected your PC".
   Verify the download against `SHA256SUMS.txt` first:
   ```powershell
   Get-FileHash .\SoundScene-Setup-0.2.2.exe -Algorithm SHA256
   ```
   Then choose **More info > Run anyway**.
3. Run the installer. It installs for the current user only and adds an entry under Settings > Apps.

The portable build is `SoundScene-Portable-0.2.2.zip`: extract it anywhere, run
`SoundScene.App.exe`, and delete the folder to remove it. Settings and the Dolby client cache stay
inside its `data` folder.

## Uninstall

Use **Settings > Apps > SoundScene > Uninstall**. It removes the install folder, shortcuts, the
Start with Windows entry, settings/scenes (unless you choose to keep them), and the copied Dolby
client cache. Dolby Access, the driver, and Dolby's `Runtime.xml` are left alone unless you enable
the optional Dolby reset.

## Known limitations

- Windows 10 support is implemented but not hardware-tested yet.
- Other DAX3 models are supported in code but unverified; the G14 is the only tested machine.
- A future DAX build that changes the native C ABI could break the bridge even if discovery works.
- Unknown profile modes are selectable, but scenes and hotkeys still target the six known profiles.
- No auto-update yet; check this releases page.
- The installer is unsigned.
