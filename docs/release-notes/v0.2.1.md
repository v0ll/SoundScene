# SoundScene 0.2.1

A lightweight tray companion for **Dolby Access** on ASUS ROG Zephyrus laptops: instant profile
switching, per-profile hotkeys, scenes, and a graphic EQ without opening the Dolby app.

## Highlights

- **Profile hotkeys** - one key per profile, or a toggle between two. The editor is available from
  the popup and the tray menu.
- **EQ editor** - ten simple sliders by default, all twenty driver bands under **Advanced**, typed
  dB values, instant writes with no Apply button, and a half-decibel flat snap.
- **Volume leveler and surround virtualizer** switches alongside the curve.
- **Scenes** - save a profile plus its Personalize curve and recall it in one click.
- **Low idle footprint** - the tray is native `Shell_NotifyIcon`; the popup is built on first use,
  and unused pages are returned after the app is idle.
- **Clean install/uninstall** - per-user installer, optional portable ZIP, no elevation, and an
  uninstaller that removes app data and shortcuts.

## Requirements

- Windows 10 version 2004 (build 19041) or newer, or Windows 11, x64.
- **Dolby Access** installed for your Windows user (free from the Microsoft Store, product ID
  `9N0866FS04W8`).
- The ASUS/Realtek **Dolby Atmos driver**, which installs the `DolbyDAXAPI` service.

**The driver alone is not enough.** The control API ships in the Dolby Access package. SoundScene
does not bundle or redistribute Dolby software.

## Install

1. Download `SoundScene-Setup-0.2.1.exe` below.
2. The installer is not code-signed yet, so SmartScreen may say "Windows protected your PC".
   Verify the download against `SHA256SUMS.txt` first:
   ```powershell
   Get-FileHash .\SoundScene-Setup-0.2.1.exe -Algorithm SHA256
   ```
   Then choose **More info > Run anyway**.
3. Run the installer. It installs for the current user only and adds an entry under Settings > Apps.

The portable build is `SoundScene-Portable-0.2.1.zip`: extract it anywhere, run
`SoundScene.App.exe`, and delete the folder to remove it. Settings and the Dolby client cache stay
inside its `data` folder.

## Uninstall

Use **Settings > Apps > SoundScene > Uninstall**. It removes the install folder, shortcuts, the
Start with Windows entry, settings/scenes (unless you choose to keep them), and the copied Dolby
client cache. Dolby Access, the driver, and Dolby's `Runtime.xml` are left alone unless you enable
the optional Dolby reset.

## Known limitations

- Tested on the ROG Zephyrus G14 GA403UV with Windows 11. Windows 10 support is implemented but not
  hardware-tested yet.
- Other DAX3-based ROG models should work, but have not been verified.
- The Dolby Access package family is currently hardcoded.
- No auto-update yet; check this releases page.
- The installer is unsigned.
