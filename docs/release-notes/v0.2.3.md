# SoundScene 0.2.3

A security and distribution release. The app behaves the same, but the Dolby client copy is now
verified before it is loaded, and every published binary is built by GitHub Actions from the tagged
commit with a build provenance attestation.

## Changes

- **Verified Dolby client cache** - the installed Dolby Access package must be Windows-signed, and
  every cached file must SHA-256 match the file in that package. A modified or stale cache is
  replaced before use, and a cache directory that is a junction or symlink is refused.
- **Tighter DLL search path** - the bridge loads the client with
  `LOAD_LIBRARY_SEARCH_DLL_LOAD_DIR | LOAD_LIBRARY_SEARCH_SYSTEM32`, so imports resolve only from
  the cache and System32, never from the application folder, the working directory, or `PATH`.
- **Friendly crash handling** - an unexpected UI exception shows a short message, saves
  `%APPDATA%\SoundScene\last-error.txt`, and keeps the tray running instead of dropping a raw
  Windows error dialog.
- **Releases are built in CI** - `.github/workflows/release.yml` builds, tests, packages, attests,
  and publishes from a tag. The workflow pins every action to a commit SHA. Local `dist` builds are
  for testing only.
- **New documentation** - [`docs/security.md`](../security.md) lists every file and registry
  value the app touches; [`docs/verify-download.md`](../verify-download.md) has the hash,
  attestation, and source-build steps; [`docs/compatibility.md`](../compatibility.md) records
  tested hardware.

## Verify the download

```powershell
gh attestation verify .\SoundScene-Setup-0.2.3.exe --repo v0ll/SoundScene
Get-FileHash .\SoundScene-Setup-0.2.3.exe -Algorithm SHA256
```

The hash must match `SHA256SUMS.txt`. The installer is still unsigned, so SmartScreen shows an
unknown publisher; choose **More info > Run anyway** after verifying.

## Compatibility

- Tested on the ROG Zephyrus G14 GA403UV with Windows 11 and Dolby Access 3.27.
- DAX3-based models such as the Zephyrus G16 should work but are still unverified. The Diagnostics
  window reports everything needed to add a row to the compatibility table.
- Requires Windows 10 2004 (build 19041) or newer, x64, **Dolby Access**, and the ASUS/Realtek
  Dolby Atmos driver. No Dolby binary is bundled or redistributed.

## Install

1. Download `SoundScene-Setup-0.2.3.exe`.
2. Verify it with the commands above.
3. Run it. It installs for the current user only and appears under Settings > Apps.

The portable build is `SoundScene-Portable-0.2.3.zip`: extract it anywhere, run
`SoundScene.App.exe`, and delete the folder to remove it.
